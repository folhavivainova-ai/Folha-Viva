# MANUAL MESTRE TÉCNICO, FUNCIONAL E VISUAL
## PLATAFORMA DE MONITORAMENTO AGRÍCOLA INTELIGENTE
**Café + Capim | Web responsivo + PWA mobile | Satélite + Clima + Offline + IA**

- **Versão:** 1.0 (Documento normativo inicial)
- **Data-base:** 20/09/2026
- **Escopo inicial:** Monitoramento de café e capim
- **Modelo de entrega:** Full-stack vertical: backend + frontend + mobile + homologação
- **Fonte central do código:** GitHub
- **Infraestrutura-alvo:** Vercel + Supabase em configuração compatível com planos gratuitos
- **Registro de execução:** Livro Raiz obrigatório

---

### Princípios Invioláveis
1. **Regra de Ouro:** Nenhuma etapa é concluída se entregar apenas backend ou apenas frontend. A entrega é sempre vertical, integrada e testada.
2. **Sem dados fictícios na fundação:** A estrutura nasce pronta para receber os dados reais do produtor, sem tabelas preenchidas com fazendas ou talhões falsos.
3. **Identidade invisível na V1:** Sem tela de login bloqueante. O produtor entra direto via sessão anônima do dispositivo e no futuro migra para conta definitiva (V19).
4. **Café e Capim:** Cada cultura possui dinâmicas separadas. Módulos como Florada são exclusivos de Café. Capim possui catálogo extensível.
5. **Transparência Agronômica:** Distinguir claramente "medido", "observado", "estimado", "inferido" e "confirmado em campo".
6. **Offline-first:** PWA com armazenamento local, fila de mutações idempotente e sincronização com retorno de conexão.
7. **Design System do Cafeeiro:** Folha Profunda (#173F2A), Folha Viva (#2F7D4A), Folha Nova (#8BCF9B), Florada (#FFFDF7), Cereja Madura (#B7372E), Ramo (#6B4A35), Solo (#D8C4A8), Atenção (#D99A22).
